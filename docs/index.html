Internet

The internet is a network. It is made up of computers and allows them to communicate with each other globally.

Web

The Web works on the internet and holds web pages and other resources that are accessed through web browsers.

How are the Internet and Web different?

The internet is like the bread of the sandwhich while the web is one of the many fillings. You can't have the web without the internet.

ASCII and Unicode

Stands for "American Standard Code for Information Interchange" and is the standard encoding for letters, numbers, etc using 7 bits per character and has 128 characters. Unicode is bigger with 8 bits per character and has 256 characters and is used for characters from various languages.

What is UTF-8

"Unicode Transformation Format - 8 Bit" is an encoding that uses 1-4 bytes per character to represent all Unicode characters.

URL

"Uniform Resource Locator" is the address of a web page or other resource that shows it's location on the internet.

Domain Name

Main name of a web page usually in it's URL. Meant to be a easily readable name for a website.

HTTP

"Hypertext Transfer Protocol" is a protocol used to transfer data or resources like web pages across the web.

HTTPS

"Hypertext Transfer Protocol Secure" is a version of HTTP that uses an encryption to protect data moving between a web browser and a web page.

IP Address

"Internet Protocol" is an address made of numbers for electronic devices connected to the internet.

DNS

"Domain Name System" helps your computer translate domain names of web pages into the IP addresses for them to be accessed.

W3C Recommendations

These are standards that guide any creation of web content so that all content is accessible and able to be used by everyone.

XML, XHTML, HTML, HTML5

"Extensible Markup Language" is a language used to store and move data, "Extensible Hypertext Markup Language" is the version of HTML that works with the language rules of XML, "HyperText Markup Language" is the original and commonly used language for writing web pages, "HTML5" is the latest version of HTML.
