Forms

the action attribute is for the url the form will take you to once form is submitted

get will send form data into the url as a query string while post sends it a different way. if changing or adding something on server use post.

preset is the actual data put into form while placeholder disappears and is not submitted. text box: use type="text" as seen below for name, email and password. text area: use textarea tag for longer messages. select box: use select tag and option tag for dropdown menus. for checkboxes and radio buttons, use type="checkbox" and type="radio".

type="email" is a HTMl5 form control. the browser will show and validate the email. The mobile keyboard will be email friendly. List of HTML5 form controls:

  • input type="color"
  • input type="date"
  • input type="datetime-local"
  • input type="email"
  • input type="month"
  • input type="number"
  • input type="range"
